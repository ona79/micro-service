# Dossier des images du site Patrimoine du Sénégal

Déposez vos photos dans ce dossier (et dans le sous-dossier `patrimoines/`) en respectant exactement les noms suivants :

- `frontend/public/images/hero.jpg` : Grande image d'accueil (paysage du Sénégal, Casamance, île de Gorée ou pirogues).
- `frontend/public/images/patrimoines/PAT-DKR-001.jpg` : Maison des Esclaves de Gorée (Île de Gorée, Dakar).
- `frontend/public/images/patrimoines/PAT-DKR-002.jpg` : Monument de la Renaissance Africaine (Ouakam, Dakar).
- `frontend/public/images/patrimoines/PAT-ZIG-003.jpg` : Cathédrale Saint-Antoine de Padoue (Centre-ville, Ziguinchor).
- `frontend/public/images/patrimoines/<codePatrimoine>.jpg` : Tout autre patrimoine ajouté via l'API (ex. Mémorial-Musée du Joola à Ziguinchor).

Si un fichier est absent, le composant `PatrimoineImage` affiche automatiquement un bloc vert clair de remplacement avec le code et le nom du patrimoine.
